# 出海广告接入指北

面向中文个人开发者的海外广告变现指南（AdMob / AdSense / AppLovin MAX / Unity LevelPlay / Meta Audience Network）。

- **在线阅读**：https://kongliuli.github.io/haiwai-ads-guide/
- **仓库**：https://github.com/kongliuli/haiwai-ads-guide

内容是按各厂商英文文档整理后的中文重写，文内带官方原文链接，不是官方镜像站。本仓库只维护文档站（`site/`），不含 SDK 包。

本地预览：`npx --yes serve site`（需用 HTTP 打开）。
