# 关于本站与版权

> 编写模型: Composer (Cursor Agent) · 2026-10-15

## 定位

本站服务对象：希望用个人身份接入海外广告变现、但更习惯阅读中文的开发者。

内容来源：各平台官方英文开发者文档与帮助中心的**公开信息架构与步骤逻辑**，经选题整合后用中文重写。

## 版权与使用边界

| 可以 | 不可以 |
|------|--------|
| 中文重写步骤、选型建议、踩坑提示 | 整页/整站 verbatim 复制官方文档 |
| 短代码片段（Gradle / Pod / JS 接入惯用写法） | 把本站冒充为 Google / Meta / Unity / AppLovin 官方中文站 |
| 链回官方原文，标注对照日期 | 批量爬取后机翻上架冒充「官方中文文档」 |

商标与产品名归各权利方所有。官方政策、价格、结算门槛以**原文页面当前内容**为准；本站可能滞后，请以文首「对照原文」链接核对。

## 贡献方式（后续）

仓库开放后，欢迎 PR：补平台深页、修正过期坐标、补充对照链接。请勿提交大段未改写的机翻官方全文。
