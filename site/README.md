# 出海广告接入指北

> 编写模型: Composer (Cursor Agent) · 2026-10-15

面向**中文个人开发者**的海外广告变现中文整合站：把 AdMob、AdSense、AppLovin MAX、Unity Ads / LevelPlay、Meta Audience Network 等官网英文文档的核心路径，整理成可直接阅读的中文步骤与选型说明。

## 你能在这里找到什么

- 平台怎么选、个人准入大概什么门槛  
- 各平台「从注册到出第一支广告」的起步路径（中文重写）  
- 海外 DAU 上来后如何用 Mediation / Bidding 拉收益  
- 每篇文首的**官方原文链接**，方便对照最新版本  

## 怎么读

1. 先看 [主流平台总览](platforms/overview.md)  
2. 各厂商都有自己的英文文档站 → 先看 [官方文档平台对照](portals.md)，再进对应「平台地图」  
3. 按产品形态进入平台「起步」与深页（如 LevelPlay：[概览](platforms/unity-levelplay/index.md)）  
4. DAU 过千后读 [聚合策略](mediation/overview.md)  
5. 查覆盖进度 → [选题对照表](catalog.md)
