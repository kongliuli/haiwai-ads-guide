# AdSense · 个人站政策红线清单

> 编写模型: Composer (Cursor Agent) · 2026-10-15  
> 对照原文：[了解 Google 发布商政策与限制](https://support.google.com/adsense/answer/10008391) · [无效流量](https://support.google.com/adsense/answer/16737) · [如何防范无效流量](https://support.google.com/adsense/answer/1112983) · [广告放置最佳做法](https://support.google.com/adsense/answer/1282097) · [AdSense 计划政策总览](https://support.google.com/adsense/answer/48182)

本页是给**个人站 / 小站**用的自查清单，不是政策全文。违规后果包括限投、停投、扣款乃至封号；最终以官方政策与账号通知为准。

## 使用方式

上线或改版前，对下列项逐条打勾。任一项不确定 → 打开对应官方链接核对，不要凭「别的站也这么干」赌运气。

---

## A. 内容与站点质量

- [ ] 站点有**足够原创、可读**的正文，不是关键词堆砌、采集站、空壳落地页  
- [ ] 无违法、危险、仇恨、过度露骨色情等**发布商政策禁止**类内容（含评论区、外链落地）  
  → [发布商政策与限制](https://support.google.com/adsense/answer/10008391)  
- [ ] 版权内容已获授权；盗版影视/软件/题库等不接 AdSense  
- [ ] 医疗、金融等敏感题材表述克制，不夸大承诺（限制类内容可能少广告或无广告，不等于「可以乱写」）  
- [ ] 导航、关于、隐私政策等基础页齐全；域名与控制台添加的站点一致

## B. 无效流量与点击

- [ ] **从不**点击自己线上广告（测广告用官方测试方式 / 未激活环境，勿用真实广告「点着玩」）  
- [ ] 不请亲友、社群「帮忙点广告」「刷刷新多出点」  
- [ ] 不买来路不明的点击、弹窗联盟、强制跳转刷量  
- [ ] 文案与 UI **不诱导点击广告**（「点右边支持本站」「点广告才能下」等一律禁止）  
  → [无效流量](https://support.google.com/adsense/answer/16737) · [防范建议](https://support.google.com/adsense/answer/1112983)

## C. 广告放置与实现

- [ ] 广告不会被误当成导航、下载、播放、关闭按钮  
- [ ] 广告标注用语合规（如「广告」「赞助商链接」），不误导  
- [ ] 页面以内容为主，广告密度不过分挤压正文  
- [ ] 未在 WebView 壳、伪装 App、强制插层里「硬塞」网页广告绕过政策  
- [ ] Auto ads / 手动单元组合后，在手机上检查误触与遮挡  
  → [广告放置最佳做法](https://support.google.com/adsense/answer/1282097) · [Auto ads 与广告单元](auto-ads.md)

## D. 流量来源与站外行为

- [ ] 主要流量可解释（搜索、社交、邮件、正常外链），而非异常机器流量  
- [ ] 付费引流渠道可追溯；避免「保证点击/展示」类黑产流量包  
- [ ] 不在站外用脚本、插件自动点自己的 AdSense 广告

## E. 账号与资料

- [ ] 支付资料、身份信息真实，与帮助中心要求一致（收款关卡见[付款要点](payments.md)）  
- [ ] 一站一审思路清晰：镜像站、跳转站、内容重复站容易出问题  
- [ ] 收到政策邮件 / 控制台警告后先停违规再申诉，勿一边违一边申  
- [ ] 站点连接与审核状态正常；反复删站重提可能拖慢审核（见[站点审核](site-review.md)）

## F. 政策中心（通过后也要盯）

账号里的 **Policy center** 用来发现、理解并修复影响出广告的问题（政策、监管类、广告主偏好等）。见[政策中心概览](https://support.google.com/adsense/answer/9485926)。

- [ ] 知道从哪里打开 Policy center，并能按站点筛选问题  
- [ ] 对「Fix」类条目：先按说明改站，再按指引 **Request review**，而不是只发邮件空喊  
- [ ] 分清：政策违规（必须改）vs 广告主偏好/限制（可能只是少广告）

---

## 政策 vs 限制（别混）

| 概念 | 含义 | 你要做什么 |
|------|------|------------|
| **发布商政策（Policies）** | 禁止变现的内容/行为 | 必须改掉，否则停投/封号风险 |
| **发布商限制（Restrictions）** | 部分类目广告主不愿投 | 可能少广告或空广告，不一定要删内容，但收益会受影响 |

详见[了解 Google 发布商政策与限制](https://support.google.com/adsense/answer/10008391) · 总览[计划政策](https://support.google.com/adsense/answer/48182)。
