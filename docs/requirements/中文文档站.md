# 需求：中文文档站（GitHub Pages）

> 编写模型: Composer (Cursor Agent) · 2026-10-15

## 目标

将各海外广告平台官网中、面向个人开发者的英文文档，**整合**后写成中文可读版本，挂 GitHub Pages，供中文开发者阅读。

## 验收（BATCH-03a/b）

- [x] `site/` Docsify 可本地 HTTP 预览  
- [x] 侧栏覆盖六入口 + 聚合 + 选题对照  
- [x] 各平台至少一篇「概览/起步」中文页，文首含官方原文链接  
- [x] 版权策略成文（不做官方镜像）  
- [x] Actions 工作流可从 `site/` 部署 Pages  
- [ ] 仓库推送到 GitHub 并开启 Pages（需用户操作）  
- [ ] 线上 URL 可打开且搜索可用  

## 非目标

- 不整站爬取机翻官方文档  
- 不替代厂商控制台与最新 Release Note
