# 中文文档站（GitHub Pages）

> 编写模型: Composer (Cursor Agent) · 2026-10-15

## 目标

把各海外广告平台官网中**面向个人开发者的英文接入文档**，按主题**整合**后写成**中文可读版本**，挂在 GitHub Pages，供中文开发者查阅。

站点根目录：`site/`（Docsify，零构建）。

## 内容策略（版权边界）

官方文档受版权与服务条款保护，**不做**整站镜像、逐页 verbatim 机翻搬运。

本站采用：

1. **选题对齐**：按官方文档信息架构列目录（见 `site/catalog.md`）  
2. **中文重写**：步骤、注意点、术语用自有表述写清「怎么做」  
3. **原文对照**：每篇文首给出官方原文链接，读者可跳回核对  
4. **短代码保留**：Gradle/Pod/JS 等官方惯用片段可保留（教学合理使用）  
5. **版本标注**：页面注明对照的官方文档大致版本/抓取日期，避免过期静默

一句话：这是**中文整合指北**，不是 Google/Meta 文档的中文镜像站。

## 站点技术

| 项 | 选择 | 原因 |
|----|------|------|
| 渲染 | Docsify | 纯 Markdown，无 Jekyll/Node 构建，Ponytail |
| 发布 | GitHub Actions → Pages（artifact） | 可从 `site/` 子目录发布，不占用仓库 `docs/` 台账目录 |
| 搜索 | Docsify 内置全文搜索插件 | 零后端 |
